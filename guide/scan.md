# 소재 스캔과 공모·지원 기회

신규 기획 전에 소재를 찾을 때 읽는다. 매주 목요일 저녁의 예약 작업 '웬즈데이터 다음 호 소재 스캔'도 이 파일을 읽고 그대로 따른다. 그래서 이 파일만 고치면 대화에서 하는 스캔과 예약 작업이 함께 바뀐다(예약 작업의 지시문은 이 파일을 읽으라는 말과 실행 조건만 담는다).

내부 기획 브리핑이므로 뉴스레터의 두 층 구조와 숫자 예산은 적용하지 않는다. 결과와 응답은 한국어로 쓴다.

## 1. 날짜

- 오늘(KST) 날짜를 확인하고, 발행 예정일 = 다음 주 수요일(오늘이 목요일이면 6일 뒤)을 계산한다.
- 스캔 기간은 발표일 기준 최근 7일을 우선하고, 후보가 부족하면 30일까지 넓힌다. 국제기구의 연간 보고서는 발표 후 60일까지 허용한다. 항목마다 발표일을 적는다.

## 2. 겹침 확인

- https://www.wednesdata.com/ 을 열어 최근 4주 안에 발행된 뉴스레터의 제목과 원자료(제목의 콜론 뒤 부분)를 적어 둔다.
- 후보가 그중 하나와 같은 원자료나 같은 주제면 '최근 4주 겹침'으로 표시한다. 겹친다고 제외하지는 않는다(지금은 신규 유입을 우선하는 시기라, 겹치더라도 새 독자를 끌 소재면 올린다).

## 3. 출처 — 이 범위 안에서만 고른다

- 국내 공식 발표: 국가데이터처(옛 통계청. 보도자료는 정책브리핑 korea.kr에도 게시), 한국은행(보도자료·BOK 이슈노트·조사통계월보·경제전망 포함), 국토교통부·한국부동산원, 고용노동부, 금융위원회·금융감독원, 관세청·산업통상자원부, 교육부, 보건복지부·국민연금공단, 한국소비자원, 국세청, 국회입법조사처·국회예산정책처, KDI·한국노동연구원·한국보건사회연구원 같은 국책연구원
- 정책보고서나 국회입법조사처 자료에 정기적으로 인용되는 금융지주·대형 증권사 부설 연구소: KB금융지주 경영연구소, 하나금융경영연구소, NH투자증권 리서치센터 등
- 국제기구: OECD, IMF, 세계은행, UN 계열(UN DESA·UNDP·UNFPA·UNESCO·WHO), ILO, BIS, WTO, Eurostat. 한국 country note와 국내 소관 부처의 보도자료(예: 교육부의 OECD 교육지표 발표)를 함께 원문으로 삼는다.
- 제외: 해외 민간 리서치(Pew·Gallup·WEF 등), 언론의 자체 분석, 민간 플랫폼·취업 포털의 설문. 보조 인용 한 문장은 허용한다.
- 매 스캔에 해외 자료를 1건 이상 포함한다.

## 4. 조사 방법

- 각 출처의 최근 발표를 웹 검색으로 찾고(최근 자료는 extended 모드), 후보마다 반드시 공식 페이지(기관 누리집의 보도자료 게시물, korea.kr 게시물, 또는 발간물 페이지)를 직접 열어 공식 명칭과 발표일을 확인한다. 확인하지 못한 자료는 제외하거나 '원문 확인 필요'로 표시한다. 뉴스 기사만 보고 수치를 적지 않는다.
- 검색 질의는 1~6단어로 짧게 쓰고 같은 질의를 반복하지 않는다.
- 하위 에이전트를 쓸 수 있으면 '국가데이터처·한국은행 / 그 밖의 국내 기관·연구소 / 국제기구 / 공모·지원 기회' 네 갈래로 나눠 병렬 조사시켜도 된다. 각 갈래에 해당 항목의 기준과 결과 항목을 그대로 전달하고, 돌아온 URL은 브리핑에 넣기 전에 직접 열어 재확인한다.

## 5. 선정 기준

1. 2030 직장인의 일상(소득·소비·주거·결혼·자산·고용)과 맞닿아 있는가
2. 뚜렷한 변화나 반전이 있는가
3. 한 장의 차트로 이야기의 결론을 보여 줄 수 있는가
4. 기존 시리즈와 이어지거나 새 앵글을 여는가
5. 독자가 자기 이야기로 읽을 수 있는가 — 독자가 흔히 품는 말·믿음·궁금증과 바로 닿고, 핵심 숫자를 독자의 횟수·시간·돈으로 바꿔 셀 수 있는가

## 6. 공모·지원 기회

소재와 별도로, 웬즈데이터가 지원해 볼 만한 데이터 활용·시각화 공모를 찾는다.

- 기본으로 볼 곳: 국가데이터처 누리집의 '공모전소식' 페이지(https://www.mods.go.kr/menu.es?mid=a10313000000)와 국가데이터처가 해마다 여는 공모
  - 국가데이터 활용대회(옛 통계데이터 활용대회, 한국통계진흥원 주관): 2026년은 4~5월 참가신청이었고, 분석 보고서와 포스터를 낸다.
  - 국가승인통계 활용 디지털콘텐츠 공모전(KOSIS): 2026년은 4~7월 접수였고, 2분 이내 영상을 낸다.
  - SGIS 활용 우수사례 공모전: 9월 전후에 열린다.
- 그 밖에 볼 곳: 다른 부처·공공연구기관·지자체의 통계·데이터 활용·시각화 공모와 국제기구의 데이터 시각화 공모. 예: 산업연구원 ISTANS 산업통계 우수활용사례 공모전, 한국문화관광연구원 문화체육관광 통계 활용대회, 서울시 빅데이터 활용 경진대회, 한국언론진흥재단 언론 통계 분석·활용 경진대회, 행정안전부 공공데이터 공모.
- 제외: 대학(원)생·초중고생 전용처럼 웬즈데이터가 자격이 안 되는 공모(통계청 논문 공모전, 전국학생 통계활용대회, 대학생 전용 시각화 공모 등). 자격이 애매하면 넣고 '자격 확인 필요'로 표시한다.
- 시기: 접수 마감이 스캔일부터 60일 안인 공모를 올린다. 해마다 열리는 공모가 올해 아직 공고되지 않았으면, 지난해 공고 시기 30일 전부터 '공고 예정(지난해 ○월 공고)'으로 미리 알린다. 국가데이터 활용대회처럼 데이터센터 방문 분석과 반출 심의로 준비가 긴 공모는 참가신청 시작 30일 전부터 알린다.
- 맞는지 보는 기준:
  1. 웬즈데이터가 이미 만드는 것(리드 차트·뉴스레터 글·데이터 카탈로그 엑셀·릴스 영상)으로 낼 수 있는가. 기존 호를 고쳐 낼 수 있으면 어느 호인지 적는다.
  2. 참가 자격(개인·팀 인원·사업자·학생 여부)
  3. 이미 공개한 작품을 내도 되는가(미발표작 조건)
  4. 수상작의 저작권·이용권이 주최 측에 넘어가는가. 넘어가면 웬즈데이터에 실은 콘텐츠를 계속 쓰기 어려우므로 반드시 적는다.
  5. 들이는 시간에 견줘 얻는 것(상금, 기관장상, 웬즈데이터의 노출과 신뢰)
- 확인: 주최 기관의 공식 공고를 직접 열어 공모명·일정·자격을 확인한 것만 쓴다. 공모전 모음 사이트(씽유 등)에서만 확인한 것은 '공식 공고 확인 필요'로 표시한다. 일정과 요강은 해마다 바뀌므로 지난해 정보를 올해 것처럼 쓰지 않는다.
- 지원은 사용자가 고른 뒤에 진행한다. 고르면 요강을 읽고, 낼 산출물과 일정을 뉴스레터 기획과 별개로 제안한다.

## 7. 출력

- 첫 줄: '{발행 예정일} 발행호 소재 후보 — {오늘 날짜} 스캔'
- 관심도 순으로 최대 5건. 항목마다: 기관명 / 공식 발표자료명(확인한 공식 URL을 링크로) / 발표일 / 핵심 수치 1~2개 / 추천 이유 / 시각화 여건(원문 차트의 유무와 종류, 원데이터 공개 여부 — KOSIS·ECOS·OECD Data Explorer·첨부 엑셀 등, 10년 이상 시계열 여부) / 예상 방향과 핵심 메시지 한 문장 / 최근 4주 겹침 여부
- '발행일 전 발표 예정': 오늘부터 발행 예정일 사이에 나올 정기 공표 2~4건(기관, 명칭, 예정일. 각 기관의 공표 일정 페이지에서 확인한 것만).
- '지원해 볼 만한 공모': 소재 후보와 섞지 않고 맨 아래에 따로 둔다. 마감이 가까운 순서로 최대 3건. 항목마다: 공모명(확인한 공식 공고 링크) / 주최·주관 / 접수 기간과 마감(D-n) / 참가 자격 / 제출물 형식 / 시상 / 웬즈데이터와 맞는 이유와 낼 수 있는 산출물 / 확인할 점(미발표작 조건, 수상작 저작권·이용권 귀속, 중복 응모 제한). 해당이 없으면 '이번에는 없음' 한 줄만 쓴다.
- 사용자가 후보 하나를 고르면 프로젝트 지침 5장 1단계(팩트체크·기획 승인)로 넘어간다.
